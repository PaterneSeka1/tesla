# Parcours utilisateurs

Une seule application ; le menu dépend des permissions (D141). Aucun rôle, permission ni mandat n'est affiché.

## Routier
Menu : **Accueil · Cours · Évaluations · Mon parcours · Mon profil** (barre inférieure sur mobile).

| Besoin | Chemin |
| --- | --- |
| Activer son compte | lien d'activation à usage unique remis par l'encadrement (`/activation#…`) ; le compte est rattaché à sa fiche existante, jamais de second profil |
| Où en suis-je ? | Accueil : étape officielle, équipe, modules étudiés, compétences, résultats récents ; Mon parcours › Progression (étape théorique par l'âge, écart, échéances), Rattrapages |
| Reprendre un cours | Accueil › « Reprendre la lecture » (dernière leçon ouverte sur l'appareil), ou Cours › module › leçon |
| Télécharger un module | Cours › module › « Télécharger pour lire sans connexion » ou « Télécharger le cours (PDF) » |
| Passer une évaluation | Évaluations › évaluation › « Commencer » (classique) ou « Mode jeu à paliers » ; « Préparer pour passer sans connexion » |
| Voir ses résultats | Mon parcours › Résultats (après examen du responsable) |
| Modifier sa fiche médicale | Mon profil › Fiche médicale : enregistrer, aperçu et impression, PDF, suppression |

## Membre de l'encadrement (chef, adjoint, assistant)
Menu : **Accueil · Routiers · Cours · Évaluations · Mon profil**.

| Besoin | Chemin |
| --- | --- |
| Ajouter un routier | réservé au responsable plein (arbitrage du 2026-10-30) ; le chef consulte Routiers et ajoute des observations |
| Consulter les cours | Cours › Bibliothèque (lecture, PDF, hors ligne) |
| Créer un contenu | Cours › Rédaction ; Évaluations › Questionnaires (réponses courtes à variantes acceptées) ; soumission au responsable |
| Voir les évaluations réalisées et les réponses | Évaluations › Questionnaires › « Résultats » (participation, copies, répartition, réponses rédigées) ; Corrections |
| Modifier sa fiche médicale | Mon profil › Fiche médicale |

## Responsable plein
Mêmes rubriques que l'encadrement, enrichies des décisions : cours et questionnaires à approuver, publications, résultats à examiner, déblocages, acquis ; fiches routiers, matricules, étapes, équipes ; rubrique **Administration** (comptes routiers).

## Administrateur (compte technique, D142)
Menu : **Accueil · Mon profil · Administration**. Seul travail : la gestion des comptes — Administration › Comptes (création, lien d'activation, désactivation) et Administration › Encadrement (désignation du responsable plein, de l'adjoint et des assistants). Mon profil : nom, mot de passe ; ni fiche médicale ni accès pédagogique.
